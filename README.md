# Bird and Block

A small Pygame example where you move a bird around the screen and collide with
an orange block. A sound plays when the bird hits the block.

## Setup

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Activate it on Linux:

```bash
source .venv/bin/activate
```

Install the requirements:

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python main.py
```

Use the arrow keys or **WASD** to move the bird.
